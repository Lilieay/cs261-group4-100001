2.  User Story

As a นักศึกษามหาวิทยาลัยธรรมศาสตร์ที่ต้องการกลับมาดูข้อมูลเตรียมสอบของรายวิชา CS

I want to บันทึกแนวข้อสอบหรือสรุป PDF แต่ละรายการที่สนใจไว้ในรายการส่วนตัว
และให้ระบบจัดกลุ่มตามรายวิชา

So that ฉันสามารถกลับมาดูผลงานที่บันทึกไว้ได้ โดยไม่ต้องค้นหาใหม่ทุกครั้ง

3.3 Authorization and Access Rules

-   ผู้ใช้ต้องเข้าสู่ระบบด้วยสถานะ Login ที่ใช้งานได้ก่อนบันทึกแนวข้อสอบหรือสรุป PDF

-   เจ้าของรายการส่วนตัวต้องอ้างอิงจากตัวตนที่ระบบยืนยันแล้ว ไม่เชื่อถือรหัสผู้ใช้ที่ส่งมาจาก
    Frontend เพียงอย่างเดียว

-   Backend ต้องตรวจสอบว่าผลงานชนิดและ ID ที่ส่งมามีอยู่จริงในระบบ

-   ผู้ใช้ต้องไม่สามารถบันทึกผลงานไปยังรายการส่วนตัวของบัญชีอื่นได้

-   รายละเอียดการตรวจสอบ Token, รหัสตอบกลับ และรูปแบบ Error ต้องสอดคล้องกับ API
    Contract

3.4 Save and Failure Rules

Successful saving

-   ระบบบันทึกแนวข้อสอบหรือสรุป PDF รายรายการและเชื่อมโยงกับบัญชีผู้ใช้ที่ถูกต้อง

-   ผลงานที่บันทึกปรากฏในรายการส่วนตัวและจัดกลุ่มใต้รายวิชาที่ถูกต้อง

-   รายการยังคงอยู่หลังโหลดหน้าใหม่หรือเข้าสู่ระบบด้วยบัญชีเดิมอีกครั้ง

-   การบันทึกผลงานชนิดและ ID เดิมซ้ำไม่สร้างรายการซ้ำ

Failed saving

-   ระบบต้องแจ้งว่าบันทึกไม่สำเร็จเมื่อการบันทึกล้มเหลว

-   ระบบต้องไม่แสดงข้อความสำเร็จหากข้อมูลไม่ได้ถูกบันทึกจริง

-   รายการส่วนตัวต้องไม่แสดงผลงานที่บันทึกไม่สำเร็จเป็นรายการที่บันทึกแล้ว

5.  U9 Test Cases

User Story: U9 --- บันทึกแนวข้อสอบและสรุป PDF รายชิ้นที่สนใจไว้ในรายการส่วนตัว
และจัดกลุ่มตามรายวิชา

Test Status: ยังไม่ได้ทดสอบ

5.1 Legacy Test Cases --- เกณฑ์เดิมก่อนเปลี่ยนมติ PO: U9-TC01--TC05
ด้านล่างเก็บไว้เพื่ออ้างอิงแนวทางเดิมที่บันทึกรายวิชาทั้งวิชา ไม่ใช้เป็นเกณฑ์ตรวจรับตามมติ PO
ใหม่

U9-TC01: บันทึกรายวิชาสำเร็จ (เกณฑ์เดิมก่อนเปลี่ยนมติ PO)

-   ข้อมูลตั้งต้น: นักศึกษา A เข้าสู่ระบบและเปิดหน้ารายวิชา CS261 ซึ่งมีอยู่ในระบบ

-   ข้อมูลทดสอบ: บัญชีทดสอบ A และรายวิชา CS261

-   ขั้นตอน: กดบันทึกรายวิชา จากนั้นตรวจรายการส่วนตัว โหลดหน้าใหม่
    และเข้าสู่ระบบด้วยบัญชีเดิมอีกครั้ง

-   ผลคาดหวัง: ระบบแจ้งสำเร็จและ CS261 ปรากฏในรายการส่วนตัวอย่างต่อเนื่อง

U9-TC02: บันทึกวิชาที่ยังไม่มีเนื้อหาได้ (เกณฑ์เดิมก่อนเปลี่ยนมติ PO)

-   ข้อมูลตั้งต้น: รายวิชา CS104 มีอยู่ในระบบแต่ยังไม่มีแนวข้อสอบหรือสรุป

-   ข้อมูลทดสอบ: บัญชีทดสอบที่เข้าสู่ระบบแล้ว และรายวิชา CS104

-   ขั้นตอน: กดบันทึก CS104

-   ผลคาดหวัง: บันทึกรายวิชาได้โดยไม่จำเป็นต้องมีแนวข้อสอบหรือสรุปก่อน

หมายเหตุ: U9-TC02 เดิมถูกแทนที่สำหรับเกณฑ์ตรวจรับใหม่ด้วย U9-TC06
(บันทึกแนวข้อสอบรายรายการ) และ U9-TC07 (บันทึกสรุป PDF รายรายการ)
เพราะมติใหม่ไม่บันทึกรายวิชาทั้งวิชา

U9-TC03: บันทึกวิชาเดิมซ้ำไม่เพิ่มรายการซ้ำ (เกณฑ์เดิมก่อนเปลี่ยนมติ PO)

-   ข้อมูลตั้งต้น: นักศึกษา A บันทึก CS261 ไว้ในรายการส่วนตัวแล้ว

-   ข้อมูลทดสอบ: บัญชีทดสอบ A และรายวิชา CS261 ที่ถูกบันทึกไว้แล้ว

-   ขั้นตอน: กดบันทึก CS261 ซ้ำ หรือส่งคำขอบันทึกซ้ำ

-   ผลคาดหวัง: CS261 ยังคงมีเพียงหนึ่งรายการในรายการส่วนตัว

U9-TC04: ไม่รับการบันทึกที่ไม่มีสิทธิ์หรือวิชาใช้ไม่ได้ (เกณฑ์เดิมก่อนเปลี่ยนมติ PO)

-   ข้อมูลตั้งต้น: เตรียมกรณีทดสอบแยกกัน ได้แก่ ไม่มี Login, Token ไม่ถูกต้อง/หมดอายุ,
    รหัสวิชาไม่มีในระบบ และพยายามอ้างบัญชีเจ้าของเป็นผู้ใช้อื่น

-   ข้อมูลทดสอบ: Token ทดสอบที่ไม่มี/ไม่ถูกต้อง, รหัสวิชาที่ไม่มีอยู่ และบัญชีทดสอบ A/B

-   ขั้นตอน: ส่งคำขอบันทึกไปยัง Backend แยกตามกรณี

-   ผลคาดหวัง: Backend ปฏิเสธคำขอที่ไม่ถูกต้อง ไม่สร้างรายวิชาใหม่ และไม่บันทึกให้บัญชีอื่น

U9-TC05: บันทึกล้มเหลวต้องไม่แจ้งสำเร็จ (เกณฑ์เดิมก่อนเปลี่ยนมติ PO)

-   ข้อมูลตั้งต้น: นักศึกษา A เข้าสู่ระบบและสามารถจำลองความล้มเหลวของการบันทึกได้

-   ข้อมูลทดสอบ: บัญชีทดสอบ A, รายวิชา CS261 และสภาวะจำลองการบันทึกล้มเหลว

-   ขั้นตอน: กดบันทึกรายวิชาในขณะที่ระบบจำลองให้การบันทึกล้มเหลว

-   ผลคาดหวัง: ระบบแจ้งว่าบันทึกไม่สำเร็จ ไม่แสดงข้อความสำเร็จ และ CS261
    ไม่ถูกเพิ่มในรายการส่วนตัว

5.2 Current Acceptance Test Cases --- เกณฑ์ตรวจรับตามมติ PO ใหม่

U9-TC06: บันทึกแนวข้อสอบรายรายการสำเร็จ

ข้อมูลตั้งต้น: ผู้ใช้ A Login แล้ว และมีแนวข้อสอบของรายวิชา CS261 อยู่ในระบบ

ขั้นตอน: ผู้ใช้กดบันทึกแนวข้อสอบรายการที่ต้องการ จากนั้นเปิดรายการส่วนตัวและโหลดหน้าใหม่

ผลคาดหวัง: ระบบบันทึกแนวข้อสอบรายการนั้นสำเร็จ และรายการปรากฏในรายการส่วนตัวของ A
ใต้รายวิชา CS261 หลังโหลดหน้าใหม่

U9-TC07: บันทึกสรุป PDF รายรายการสำเร็จ

ข้อมูลตั้งต้น: ผู้ใช้ A Login แล้ว และมีสรุป PDF ของรายวิชา CS261 อยู่ในระบบ

ข้อมูลทดสอบ: บัญชีทดสอบ A และ ID ของสรุป PDF CS261 ที่มีอยู่จริง

ขั้นตอน: ผู้ใช้กดบันทึกสรุป PDF รายการที่ต้องการ จากนั้นเปิดรายการส่วนตัวและโหลดหน้าใหม่

ผลคาดหวัง: ระบบบันทึกสรุป PDF รายการนั้นสำเร็จ และรายการปรากฏในรายการส่วนตัวของ A

U9-TC08: แสดงรายการที่บันทึกใต้รายวิชาที่ถูกต้อง

CS240

ขั้นตอน: บันทึกแนวข้อสอบและสรุป PDF แต่ละรายการ แล้วเปิดหน้ารายการส่วนตัว
