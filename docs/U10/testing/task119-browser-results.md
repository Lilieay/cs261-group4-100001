# ผลทดสอบบนเบราว์เซอร์ Task119

ทดสอบ U10-TC02 ใน Chrome 157 บน Windows ด้วยข้อมูลสังเคราะห์และ API จำลองในเครื่อง เบราว์เซอร์ใช้หน้าเว็บและ Express proxy ของโปรเจกต์ และเปิดไฟล์ PDF ทดสอบจาก Task94 ในตัวอ่าน PDF ของ Chrome

## เปิดจากกลุ่มวิชาเดียวกัน

| สิ่งที่กดจากรายการบันทึก | ผลที่ตรวจได้ |
| --- | --- |
| หัวข้อวิชา CS261 | เปิดหน้าวิชา Introduction to Software Engineering และแสดงแนวข้อสอบ G1 กับ G2 |
| เปิดอ่าน G2 | แสดงชื่อ G2 - Final exam guide และหัวข้อ Requirements and architecture ผ่านคำขอ `GET /api/guides/42` |
| เปิดอ่าน S1 | แสดงชื่อ S1 - CS261 summary และเปิดไฟล์ `S1-CS261.pdf` จาก `GET /api/summaries/42/file` ตัวอ่านแสดงข้อความใน PDF ของ CS261 |

G2 กับ S1 ใช้เลข ID เดียวกันในข้อมูลทดสอบ เพื่อยืนยันว่าปุ่มเปิดอ่านเลือกทั้งประเภทและ ID ของเอกสารได้ถูกต้อง

## ทำซ้ำ

1. ใช้บัญชีทดสอบบันทึกแนวข้อสอบสองชิ้นที่มีชื่อและหัวข้อต่างกัน พร้อมสรุป PDF หนึ่งชิ้นในวิชาเดียวกัน
2. เปิดหน้า **รายวิชาที่บันทึก** ตรวจว่าทั้งสามรายการอยู่ในกลุ่มเดียวกัน กดชื่อวิชาและตรวจรหัสกับชื่อวิชา แล้วกลับมาที่รายการบันทึก
3. กด **เปิดอ่าน** ของแนวข้อสอบชิ้นที่สอง ตรวจชื่อและหัวข้อ แล้วกดกลับรายการบันทึก
4. กด **เปิดอ่าน** ของสรุป ตรวจชื่อสรุป ชื่อไฟล์ และข้อความที่เห็นในตัวอ่าน PDF
5. หน่วงคำขอ `DELETE` แล้วกด **นำออก** จากนั้นย้ายไปพิมพ์ในช่องค้นหาก่อนคำขอเสร็จ เมื่อรายการหาย ให้กด Space ต่อ ผลที่ตรวจได้คือช่องค้นหายังมีโฟกัสและไม่มีคำขอ `DELETE` เพิ่ม ลองซ้ำโดยย้ายไปตัวกรองประเภทแล้วตรวจว่าโฟกัสยังอยู่ที่ตัวกรอง
