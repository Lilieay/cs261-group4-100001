# Task126: U7 – ทดสอบระบบและตรวจรับ U7

> เอกสารสำหรับบันทึกผล System / End-to-End Test, Regression Test และ UAT ของ U7  
> **ข้อสำคัญ:** เอกสารนี้เป็นรายงานของ Task126 ไม่ใช่รายงาน Task121 และจะไม่ถือผลจาก mock ว่าเป็นหลักฐานยืนยันการทำงานของระบบจริง

## 1. วัตถุประสงค์

ทดสอบระบบ U7 ที่เชื่อมต่อแล้วให้ครบ U7-TC01–TC08 ผ่านเส้นทางผู้ใช้จริง ตั้งแต่หน้าเว็บผ่าน Frontend proxy และ Backend ไปยัง SQL Server และ PDF storage ตามกรณีที่เกี่ยวข้อง ตรวจ regression เฉพาะจุดที่ Story นี้กระทบ และทำ UAT ร่วมกับ Product Owner (PO)

ต้องเชื่อมโยงแต่ละ TC กับผล Unit, API, Integration, System และ UAT ที่เกี่ยวข้อง โดยแยกให้ชัดว่าการทดสอบแต่ละระดับยืนยันอะไร และไม่ใช้ผลจาก mock เพื่อรับรองชั้นระบบจริง
